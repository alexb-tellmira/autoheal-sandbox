# autoheal-sandbox

Scratch repo for testing examdojo-gtm's autoheal merge design: a required `autoheal-review` commit
status, GitHub auto-merge switched on with a GitHub App token, and deploys started by the merge.
Every workflow here is a stub. PR titles steer the stubs: `[ci=N]` and `[review=N]` set how many
seconds each takes, `[fail-review]` makes the review fail.
